## CBOL Project Context

CBOL (AI Messaging Hub) is an instant messaging project with:
- Message reception (接回话)
- Message management (回话管理)
- Message forwarding (回话转发)
- AI processing
- Agent transfer
- WebSocket real-time communication
- State machine for conversation lifecycle

These reference projects provide patterns, best practices, and implementation ideas for each of these areas.
